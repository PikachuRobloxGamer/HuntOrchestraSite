# Hunt Orchestra website

Open `index.html` in any browser to view the site. No build step or server is needed.

## What's in this folder

- `index.html` — the full website (styles and scripts are inside this one file)
- `assets/logo.png` — Hunt Orchestra logo, transparent background
- `assets/logo-dark.png` — lighter logo used in dark mode
- `assets/emblem.png` / `assets/emblem-dark.png` — violin emblem used in the menu bar and as the browser tab icon
- `assets/logo-original.png` — the logo as originally provided

## Before publishing, update these placeholders

- Concert dates in the season list (search `var events` in index.html)
- Weekly schedule table (class periods and sectional times)
- Director names in the Contact section
- The contact form only shows a confirmation message; connect it to a form service or school email to receive messages

## Fundraiser link

All donate buttons point to https://app.99pledges.com/fund/huntorchestra2026.
To change it, find and replace that address in index.html.

## Putting it online

Upload the whole folder (keep `assets` next to `index.html`) to any static host, such as GitHub Pages, Netlify or the school's web space.
